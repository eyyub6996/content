%% Révisions cumulatives — une série par semaine
# R | Révisions cumulatives | Une série par semaine pour ne rien oublier de ce que tu as déjà appris

:::idee Pourquoi réviser ce qu'on a « déjà vu » ?
Le cerveau oublie vite : sans révision, on perd environ la moitié d'une méthode en une semaine.
Mais chaque fois qu'on la **ressort de sa mémoire** (sans regarder le cours !), elle se grave plus profondément. C'est la **répétition espacée**.
Ces séries mélangent les chapitres déjà étudiés. Elles sont courtes (30 à 45 minutes). Fais-les le **dernier jour de chaque semaine**, comme indiqué dans le planning.
:::

:::methode Comment faire une série de révision
+ Mets-toi un chronomètre. Pas de cours, pas de formulaire.
+ Fais tout, même si tu hésites : écris ce que tu penses.
+ Corrige avec les réponses (à la fin de cette partie).
+ Pour chaque erreur, note dans ton **carnet d'erreurs** : l'exercice, l'erreur, la règle correcte. Relis ce carnet chaque semaine.
+ Si une série est ratée à plus de 30 %, relis la section du cours correspondante avant de continuer le planning.
:::

@exo 3
Développe, réduis, puis factorise : $E = (x + 3)^2 - (x + 3)(2x - 1)$.
@sol
Développé : $x^2 + 6x + 9 - (2x^2 - x + 6x - 3) = x^2 + 6x + 9 - 2x^2 - 5x + 3 = -x^2 + x + 12$.
Factorisé (facteur commun $x + 3$) : $(x + 3)\big[(x + 3) - (2x - 1)\big] = (x + 3)(4 - x)$.
Vérif. : $(x + 3)(4 - x) = 4x - x^2 + 12 - 3x = -x^2 + x + 12$ ✔
@check same((x+3)**2-(x+3)*(2*x-1), (x+3)*(4-x)) and same((x+3)*(4-x), -x**2+x+12)
@end

@exo 4
Résous $\dfrac{x^2 - 4}{x + 1} \geq 0$.
@sol
Condition $x \neq -1$. $x^2 - 4 = (x - 2)(x + 2)$ : racines $-2$ et $2$ ; dénominateur nul en $-1$.

:::signes
x | -\infty | -2 | -1 | 2 | +\infty
x-2 | - | | - | | - | 0 | +
x+2 | - | 0 | + | | + | | +
x+1 | - | | - | 0 | + | | +
\text{quotient} | - | 0 | + | ‖ | - | 0 | +
:::

$S = \fo{-2}{-1} \cup \fo{2}{+\infty}$.
@check ineq((x**2-4)/(x+1)>=0, Union(Interval.Ropen(-2,-1), Interval(2,oo)))
@end

@exo 4
Étudie les variations de $f(x) = (x - 2)e^x$ et donne son minimum.
@sol
$f'(x) = e^x + (x - 2)e^x = (x - 1)e^x$. $e^x > 0$ → signe de $x - 1$.
$f$ ↘ sur $\of{-\infty}{1}$, ↗ sur $\fo{1}{+\infty}$. Minimum $f(1) = -e \approx -2{,}72$.
@check der((x-2)*exp(x), (x-1)*exp(x))
@end

@exo 4
$f(x) = \dfrac{\ln x}{x}$ sur $\oo{0}{+\infty}$.
a) Calcule $f'(x)$ et étudie les variations de $f$.
b) Calcule $\displaystyle\int_1^e f(x)\dx$.
@sol
a) $f'(x) = \frac{1 - \ln x}{x^2}$ : positif si $\ln x < 1$, c'est-à-dire $x < e$. $f$ ↗ sur $\of{0}{e}$, ↘ sur $\fo{e}{+\infty}$ ; maximum $f(e) = \frac{1}{e}$.
b) Forme $u'u$ avec $u = \ln x$ : primitive $\frac{(\ln x)^2}{2}$. $\left[\frac{(\ln x)^2}{2}\right]_1^e = \frac{1}{2} - 0 = \frac{1}{2}$.
@check der(log(x)/x, (1-log(x))/x**2) and integ(log(x)/x, 1, E, Rational(1,2))
@end
