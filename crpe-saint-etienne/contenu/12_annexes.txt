## Z.1 Formulaire de mathématiques

| Notion | Formule / règle |
| Pourcentage | $t\,\%$ de $A$ : $A \times \frac{t}{100}$ ; hausse de $t\,\%$ : $\times \left(1 + \frac{t}{100}\right)$ ; baisse : $\times \left(1 - \frac{t}{100}\right)$ |
| Évolution | taux $= \frac{V_{\text{arrivée}} - V_{\text{départ}}}{V_{\text{départ}}}$ ; évolutions successives : on multiplie les coefficients |
| Vitesse | $v = \frac{d}{t}$ ; $d = v \times t$ ; $t = \frac{d}{v}$ ; 1 m/s = 3,6 km/h |
| Échelle | distance sur le plan ÷ distance réelle (même unité) |
| Fractions | $\frac{a}{b} + \frac{c}{b} = \frac{a + c}{b}$ ; $\frac{a}{b} \times \frac{c}{d} = \frac{ac}{bd}$ ; $\frac{a}{b} \div \frac{c}{d} = \frac{a}{b} \times \frac{d}{c}$ |
| Puissances | $a^m \times a^n = a^{m+n}$ ; $\frac{a^m}{a^n} = a^{m-n}$ ; $a^0 = 1$ ; $a^{-n} = \frac{1}{a^n}$ |
| Identités | $(a + b)^2 = a^2 + 2ab + b^2$ ; $(a - b)^2 = a^2 - 2ab + b^2$ ; $(a + b)(a - b) = a^2 - b^2$ |
| Fonctions | linéaire $f(x) = ax$ (proportionnalité) ; affine $f(x) = ax + b$ ; $a = \frac{f(x_2) - f(x_1)}{x_2 - x_1}$ |
| Pythagore | $ABC$ rectangle en $A$ ⇔ $BC^2 = AB^2 + AC^2$ |
| Thalès | $(MN) \parallel (BC)$ ⇒ $\frac{AM}{AB} = \frac{AN}{AC} = \frac{MN}{BC}$ |
| Trigonométrie | $\cos = \frac{\text{adj.}}{\text{hyp.}}$ ; $\sin = \frac{\text{opp.}}{\text{hyp.}}$ ; $\tan = \frac{\text{opp.}}{\text{adj.}}$ |
| Agrandissement de rapport $k$ | longueurs $\times k$ ; aires $\times k^2$ ; volumes $\times k^3$ |
| Périmètres | carré $4c$ ; rectangle $2(L + \ell)$ ; cercle $2\pi r = \pi d$ |
| Aires | carré $c^2$ ; rectangle $L\ell$ ; triangle $\frac{bh}{2}$ ; parallélogramme $bh$ ; trapèze $\frac{(B + b)h}{2}$ ; disque $\pi r^2$ |
| Volumes | pavé $L\ell h$ ; cube $a^3$ ; prisme et cylindre : $\mathcal{B} \times h$ ($\pi r^2 h$) ; pyramide et cône : $\frac{1}{3}\mathcal{B} h$ ; boule $\frac{4}{3}\pi r^3$ |
| Unités | 1 m² = 100 dm² = 10 000 cm² ; 1 ha = 10 000 m² ; 1 m³ = 1 000 dm³ = 1 000 L ; 1 cm³ = 1 mL |
| Statistiques | moyenne $= \frac{\sum x_i n_i}{\sum n_i}$ ; médiane : série rangée, valeur du milieu ; étendue = max − min |
| Probabilités | $P(A) = \frac{\text{cas favorables}}{\text{cas possibles}}$ ; $P(\bar A) = 1 - P(A)$ ; arbre : on multiplie sur un chemin |
| Arithmétique | $a = bq + r$, $0 \leq r < b$ ; PGCD : facteurs communs, plus petit exposant ; PPCM : tous les facteurs, plus grand exposant |

## Z.2 Fiche mémo de grammaire

| Question | Test / réponse |
| Sujet | encadrer par « c'est… qui » ; remplacer par *il / ils* |
| COD | pronominaliser par *le, la, les, en* ; pas de préposition |
| COI / COS | préposition *à / de* ; pronominaliser par *lui, leur, en, y* |
| Attribut du sujet | après un verbe d'état (*être, paraître, sembler, devenir, rester, demeurer, avoir l'air*) ; pronominaliser par *le* |
| Complément de phrase | supprimable **et** déplaçable |
| Complément du nom | GN prépositionnel dans un GN (*la maison **de mon père***) |
| Épithète / apposition | adjectif collé au nom / détaché par une virgule |
| Relative | introduite par un pronom relatif, qui a une fonction dans la subordonnée |
| Complétive | introduite par *que* conjonction, qui n'a pas de fonction ; souvent COD |
| Circonstancielle | conjonction (*quand, parce que, pour que, bien que, si…*) ; valeur : temps, cause, conséquence, but, concession, condition, comparaison |
| Participe passé | avec *être* : accord avec le sujet ; avec *avoir* : accord avec le COD placé **avant** |

| Verbe | Passé simple (il / ils) | Futur (je) | Subjonctif présent (que je) |
| être | il fut / ils furent | je serai | que je sois |
| avoir | il eut / ils eurent | j'aurai | que j'aie |
| aller | il alla / ils allèrent | j'irai | que j'aille |
| faire | il fit / ils firent | je ferai | que je fasse |
| venir | il vint / ils vinrent | je viendrai | que je vienne |
| prendre | il prit / ils prirent | je prendrai | que je prenne |
| voir | il vit / ils virent | je verrai | que je voie |
| pouvoir | il put / ils purent | je pourrai | que je puisse |
| savoir | il sut / ils surent | je saurai | que je sache |
| vouloir | il voulut / ils voulurent | je voudrai | que je veuille |
| devoir | il dut / ils durent | je devrai | que je doive |
| naître | il naquit / ils naquirent | je naîtrai | que je naisse |

## Z.4 Checklists des derniers jours

:::check La semaine d'avant (22 – 28 mars 2027)
[ ] Convocation imprimée, lieu et horaires vérifiés, trajet repéré (transports, parking, temps de marge)
[ ] Pas de nouveau chapitre : relire les fiches, le formulaire, le carnet d'erreurs, les cartes mémoire
[ ] Une rédaction chronométrée (1 h) et un exercice de maths de chaque type
[ ] Coucher à heure fixe ; activité physique légère
:::

:::check La veille (29 mars)
[ ] Sac prêt : convocation, **pièce d'identité**, 2 stylos bleus ou noirs, crayon, gomme, règle, équerre, compas, rapporteur, montre (sans connexion), eau, en-cas
[ ] Relire 20 minutes (formulaire, tableau des fonctions, repères) puis s'arrêter
[ ] Dîner léger, coucher tôt
:::

:::check Le jour J (30 et 31 mars)
[ ] Arriver **30 minutes** en avance
[ ] Lire tout le sujet (5 min), répartir le temps, commencer par ce que l'on maîtrise
[ ] Rédiger des réponses complètes et justifiées ; soigner l'écriture et la présentation
[ ] Garder **15 minutes** pour relire l'orthographe (accords !)
[ ] Entre les épreuves : ne pas refaire le sujet avec les autres candidats
:::

:::check Avant chaque oral
[ ] Convocation, pièce d'identité, montre ; tenue correcte et confortable
[ ] Présentation de 5 minutes répétée à voix haute (chronométrée)
[ ] Fiches relues : laïcité, obligations du fonctionnaire, protection de l'enfance, harcèlement, école inclusive
[ ] Pendant l'épreuve : regarder le jury, parler posément, reformuler les questions, rester calme et souriante
:::

## Z.7 Sources officielles à consulter

:::coeur Les sites de référence
- **devenirenseignant.gouv.fr** : descriptif des épreuves, calendrier, sujets zéro et sujets des sessions précédentes, rapports de jury, inscription.
- **Cyclades** (accessible depuis devenirenseignant.gouv.fr) : inscription, convocations, résultats.
- **ac-lyon.fr** (académie de Lyon) : informations sur le concours dans l'académie, résultats, lieux des épreuves.
- **eduscol.education.fr** : programmes de l'école (cycles 1 à 3) et du collège (cycle 4), terminologie grammaticale, ressources.
- **legifrance.gouv.fr** : arrêtés fixant les modalités du concours ; Code de l'éducation.
:::

Les dates, durées et coefficients de ce guide reprennent les informations publiées pour la session 2027 à la date de rédaction (septembre 2026). Les textes officiels **font foi** : en cas de différence, suivre le site officiel et la convocation.
:::
